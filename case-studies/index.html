Nexora Global Ventures · Plywood trading · Perumbavoor

A khata-style ledger app that runs for about ₹700 a month

A plywood trader needed a simple party ledger with the lowest possible running cost. We built it on one small server with SQLite and hourly backups. When old data was migrated, statement PDF exports maxed out the CPU. We measured the cause and rewrote the export, making it about 15× faster on the same server.

  • Django
  • SQLite
  • 1 GB droplet
  • ReportLab
